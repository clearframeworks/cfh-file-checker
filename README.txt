CFH File Checker — early build

Run CFH-File-Checker-Setup.exe on Windows to install the application in your user profile and create desktop and Start menu shortcuts. The installer is unsigned and Windows may show a warning. The application requires Windows PowerShell, .NET Framework and GitHub CLI; the setup includes the app files but not GitHub CLI. Install GitHub CLI from https://cli.github.com/ if needed and sign in using the button. Enter a new repository name in account/name format and choose Create private workspace. GitHub Actions must be enabled on that account and may have usage or billing limits. If using the source package instead, run Install.cmd.

Enter a direct public HTTPS link to a file up to 100 MiB. The app submits the link to a private GitHub Actions workflow. A GitHub-hosted runner downloads the file, calculates its SHA-256 hash, updates ClamAV signatures and scans the file in a restricted Docker container without network access. Use Check result, or open the Actions page for the full log and hash.

The download link, its query string, logs and workflow inputs can be visible to repository collaborators and GitHub. Do not submit secret or private URLs. Scanned files are not intentionally uploaded as artifacts; imported text files are stored in the private repository. GitHub runs on third-party infrastructure and its retention, network, logs and service policies apply. This tool does not execute downloaded files. It is not a general malware sandbox or a guarantee of safety. Archives and formats may not be fully analyzed; a lack of detection does not mean a file is safe. Failed scans must be treated as unknown. It supports public HTTPS URLs only.

To uninstall, choose Uninstall CFH File Checker in the Start menu. Unchanged installed files and this app's shortcuts are removed; changed or unrelated files are kept. Settings remain in %LOCALAPPDATA%\CFH File Checker. The GitHub repository and its run logs remain in your account until you remove them separately. Setup and uninstall do not delete remote files.

Choosing software: Prefer projects with an identifiable upstream, active maintainers, a published security reporting process, recent supported releases, traceable downloads and a clear open-source license. Check known advisories, release integrity, dependencies, and trademark terms for each version. A popular project or clean antivirus scan does not prove safety. The scanner does not evaluate these signals automatically.

Remote text workspace: After setup, choose Text workspace to import a public UTF-8 text file up to 1 MiB, replace literal text, append text, or remove the current file. Import requires a completed ClamAV scan with no known detection. Use View files on GitHub to inspect or intentionally download a file. Operations do not execute imported content. Use Check result to see whether an operation succeeded. Files are stored in the private GitHub repository; GitHub stores prior versions in Git history even after removal. Links, search and replacement or appended text may be visible in Actions history. Do not use this workspace for secrets. This is a limited text workspace, not a general-purpose sandbox, binary editor or secure deletion service.

GitHub source: Choose Review GitHub source to inspect dated repository metadata and create a public fork in the signed-in GitHub account without cloning to this PC. GitHub's license identification and recent activity are clues, not proof of open-source status, project support or safety. Review identity, maintainers, advisories, dependencies, licensing and the exact revision yourself before proceeding. Public forks are visible to everyone and retain GitHub history. Creating a fork does not scan or execute source and does not make it ready for distribution. Use GitHub's web editor for supported text changes; files stay on GitHub unless you choose to download them.

Scan reviewed commit: The app can retrieve a public project's exact commit as a ZIP on a GitHub-hosted runner, check archive limits, scan it with ClamAV, and check supported dependency lockfiles with OSV-Scanner. It never executes the project's source. Source archives must be at most 10 MiB, 1,000 entries and 100 MiB expanded; symlinks, special files and unsafe names are rejected. It checks up to 50 supported lockfiles, each up to 2 MiB and 10 MiB total. Missing lockfiles, unsupported formats, submodules and Git LFS content are not covered; cross-folder workspace references may also be missed. The network-enabled dependency scanner sends package names and versions to OSV.dev and may contact other services; repository names, commit IDs, findings and run logs are visible to repository collaborators and GitHub. Scanner results are incomplete evidence, not a safety or license guarantee. Signatures and advisories change over time.

Remote ZIP workspace: Choose ZIP workspace to scan and inventory the entry metadata of a public HTTPS ZIP or remove one named file, without unpacking the archive into paths or executing it. Inspection does not read or verify every entry's contents. Results are GitHub Actions artifacts retained for one day, available from the run page; downloading them is your choice. After checking the result, Delete last ZIP output deletes that run's artifact; it does not delete run logs. GitHub repository collaborators can see links, entry names, and run logs. GitHub's retention and deletion policies apply. ZIPs are limited to 10 MiB, 1,000 entries, 25 MiB per entry, 100 MiB expanded, and a 100:1 ratio; encrypted entries, symbolic links, duplicates, and unsafe paths are rejected. Nested archives are treated as files, not edited recursively. Antivirus checks do not prove an archive is safe.

After checking a successful ZIP result, View last ZIP inventory displays entry names and sizes in the app without downloading the archive. Copy file from ZIP reads one named entry into a fixed filename on the remote runner and includes it in the one-day artifact as selected-file.bin. It does not run the copied file. Downloading it would place that potentially unsafe file on your PC, so do so only deliberately.
